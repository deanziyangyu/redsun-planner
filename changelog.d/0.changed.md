Cap NumPy below 2.5 so the development lock resolves the same 2.4 line as the Redsun application, while the package still installs alongside the acquisition host's NumPy 1.26. The planner uses no NumPy 2.5-only or 1.x-only API; the range stays `>=1.24,<2.5` rather than pinning one host's version.

Command only the axes an adaptive-broom move changes. A host stage may treat a restated
target as a no-op and skip it, and a client that waits on that axis then waits for a
position nothing will move: measured on the ASI stage on 2026-10-31, a raster whose y
stayed at one value hung for the 60 s move timeout on its nineteenth frame because y read
back one controller count (0.18 um) away from the commanded value. The plan now commands
y only when the row changes and x alone on the frames that stay in the row.
